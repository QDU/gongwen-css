公文 HTML 编写指南

查看 Markdown 示例

引用 gongwen.css，并将一份公文放在单个 <article class="gongwen"> 中。优先使用下表中的 HTML5 结构；标题编号、缩进、表格和打印分页由样式自动处理。每个示例的源码都直接从其模板生成。

标题和主送机关

把公文标题与主送机关放在根元素的直接子级 header 中。标题后面的段落自动取消首行缩进。

正文段落

普通段落首行缩进两字。表格、页眉页脚、落款和定义列表中的内容不缩进。

不套用公文样式（gw-raw）

把不应套用公文版式的内容放进 gw-raw。其中的标题不编号，段落不缩进；默认显示浏览器样式，也可由宿主站点单独设置。

四级自动编号标题

按层级使用 h2 至 h5；计数器会在进入下一级标题时重置更低级序号。标题加 gw-nonum 可取消显示和递增。

黑体和楷体引导语

strong 使用黑体，em 使用楷体且保持正体，二者都可直接嵌在正文段落中。

专栏

用 aside 表示专栏，直接子级 header 是专栏标题，其余段落按专栏字数排版。

表格

使用原生表格语义。表头下方和表格上下方显示横线，第一列右侧显示竖线。

附件说明：单个附件

一个 dd 不自动编号。定义列表的第一列放“附件：”，正文从第二列开始。

附件说明：多个附件

两个或更多 dd 自动生成 1.、2. 序号，续行与附件文字对齐；十个及以上附件可增大 --gw-att-marker。

落款：无印章和有印章

用 address 包含署名机关与日期。日期使用 time；加 gw-sealed 可为印章留出位置。

附件页

将附件内容放进 section。屏幕上显示分隔线，打印时附件另起一页，并重新开始标题编号。

版记

根元素最后一个 footer 会使用版记专用页。前两段形成三条分隔线，包含 time 的行会左右对齐。

调试视图（gw-debug）

在根元素加 gw-debug 显示排版网格和元素框：蓝色竖线为字距网格，红色横线为行距网格，绿色虚线为块级元素，黄色底为行内元素，紫色底为自动编号。只绘制背景和轮廓，不改变排版；网格按正文字号和行距绘制，专栏和版记使用各自的字距行距。

首页隐藏页码

默认每页都有页码。需要隐藏首页页码时，在公文根元素上增加 gw-no-first-page-number；后续页仍按奇偶页显示页码。

此根类只切换首页页码显示，不改变纸张尺寸、边距、版心或后续页码。

打印、字体和浏览器

打印选择 A4、100% 缩放、“默认”页边距，并关闭浏览器页眉页脚。版记会另起偶数页；版记页和其前的空白页不显示页码。页码边距框要求 Chromium 131 或更新版本。

ASCII 字母、数字和标点优先使用 SimSun（宋体）。建议安装 SimSun 以获得一致的字形；未安装时使用系统中可用的宋体回退。Less 构建时展开嵌套；CSS 使用原生 @scope，需要 Chrome 118+、Safari 17.4+ 或 Firefox 146+。

Chrome 打印预览中的纸张边距应保持“默认”，不要再叠加自定义浏览器页边距。
